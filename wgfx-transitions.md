# WGFX transition adaptations

The user-supplied 60+ Transitions WGFX.prfpset is a PremiereData v3 XML file. Its hierarchy contains 74 designs across 10 groups, represented by 118 preset components / 367 effect instances. Agent Cut now offers 74 named WGFX adaptations alongside its seven existing transitions. No Adobe installation, third-party effect plugin, cloud service or internet connection is needed at runtime.

## Choose a transition

**Story Studio:** Choose Scene transition and Duration (0.1–2 seconds). For an existing story, Save story changes and Compose preview. The images extend equally around their original boundary to create the overlap. Narration, subtitle times, scene markers and final duration are preserved. A transition must be shorter than every scene; reduce its duration if a scene is too short. Cut / no transition restores straight cuts. Saved settings reload with the draft. Older stories retain straight cuts.

**Main v2 editor:** Select the outgoing video item → Inspector mode: Advanced → Transition. Pick a WGFX entry and overlap duration. Zero removes it. Normal timeline transitions overlap adjacent clips and shorten their combined duration; they follow the existing editor behavior. Story Studio's duration-preserving placement is separate. Review a composed preview after changes. The ordinary plan / revision / commit / undo safeguards apply.

**Codex/MCP:** `story_sync action=transition_styles` enumerates the choices. Generate/update a story with `transitionKind` and `transitionSeconds`. Supply the latest project/story guards and current imageIds when updating. For an existing sequence, use the selected `sequence_transition` contract and `kind`, e.g. `wgfx_zoom_01`; preview its candidate before applying. No new top-level MCP tool was added.

## Fidelity and limits

These are adapted recipes, not an Adobe preset import engine or a claim of identical Premiere output. The preset names and numeric control curves come from the supplied XML. Nine normalized linear samples drive the adaptations. Adobe's Bezier tangents and proprietary operator behavior differ.

- Geometry: sampled scale, rotation, position and anchor-point motion, rendered as native affine perspective transforms.
- Offset: wrapped image shifts.
- Channel Blur: approximated by animated RGB separation.
- Motion Blur: a bounded Gaussian blur during the transition.
- Echo: a three-frame trail; Stretch Glow adds brightness.
- Lens Distortion and Turbulent Displace: radial / sinusoidal pixel mappings.
- Solid Composite and Noise HLS: brightness/saturation and deterministic grain approximations; packed Adobe colors and blend modes are not reproduced.
- Mirror and Invert operators are not executed. Static mirror scaffolding is normalized; borders use wrap/clamp rather than Adobe's reflected tiles.

Every WGFX choice is labeled adapted. Render metadata lists the original effects and omitted operators. Some source characteristics may be absent or look different. Fast zoom/glitch effects can render more slowly on CPU. Preview the actual footage before choosing a preset.

Composed frames, full playback/export, bounded preview clocks, nested sequence sources and caption burn-in use the same transition renderer. Bounded previews include a small history window for temporal effects. Frozen jobs record the recipe digest and refuse changed recipes on retry/apply. Existing project data is not changed by installation.

## Evidence / development

`wgfx-source-report.json` preserves the source SHA-256, object IDs, effect chains, literal keyframe strings and inspection limitations. This is static XML evidence, not a Premiere runtime observation. Original source SHA-256: 8d858d25a993052661ebfccbb0cc50b8db89cbee2d9bf91bae3e24c6bf5f22e9.

`wgfx-recipes.json` is generated by scripts/import-wgfx.py from the explicit local source. It contains numeric recipes only; no XML, URLs, expressions or executable source is loaded from the preset at runtime. No original preset is installed into Premiere or modified.

Run `npm run test:wgfx` for the contracts, all 74 actual renders, narration/caption timing, resource identity and bounded-preview checks. Run `npm test` for the existing regression suite. See wgfx-verification.json and the agent-cut-wgfx-demo folder for results and exported previews.
