# Animated adjustment layers — 2026-10-17

Contract agentcut.effects.adjustment-animation.v1 extends timed adjustment spans with brightness/contrast/saturation keyframes. This is a scoped Agent Cut implementation; original Premiere runtime/default evidence remains unknown.

adjustment_keyframes(sequenceId,trackId,adjustmentId,property,frames) replaces one correction property's automation. adjustment_keyframes_clear takes the same IDs and optional property, removing one property's points or all span automation. Points use the existing 1–32-frame schema, value bounds and linear/hold/ease_in/ease_out/ease_in_out/bounded-bezier interpolation. Bezier requires control1/control2 in [0,1]. Rotation, opacity, volume and other clip-only channels reject on corrections. Unknown spans/fields, locked tracks, duplicate/unsorted points, invalid values/handles and points beyond the correction duration reject atomically.

Time is seconds relative to the correction **start**, not absolute sequence or source time. Animated values override the corresponding static value, hold at endpoints and apply only within the span's existing start-inclusive/end-exclusive interval. Moving the interval moves the animation; shortening the interval rejects stranded points unless automation is updated/cleared in the same batch. Clearing restores static values. The same shared curve evaluator/encoder expressions are used for clip and adjustment animation. Correction stack order, mute/solo, lower-track scope, audio isolation, project/revision/plan guards and undo/redo are unchanged. Participating adjustment layers still reject structural insert/range edits; this increment does not silently ripple them.

The purple track's Animate correction control selects an adjustment inspector. It reuses the property picker, curve plot, point editing/navigation and clear controls, restricted to the three correction properties. Displayed times explicitly say Adjustment-local. Preview, playback and export use the same native filter graph. Older apps/processes require restart/reconnect to load this schema.

adjustment-tests.mjs checks deterministic plans, reopen, undo/redo, bounds/property/lock failures, shortened-span rejection and repeated clear no-ops. Real FFmpeg tests evaluate eased saturation plus custom brightness/contrast curves at a nonzero span start, verify unchanged color outside the span and composed-frame/export agreement. Existing tests cover lower-only scope, mute/reorder and preserved audio. The synthetic browser workflow tests adding correction points, animated preview, clear and undo with real Store/Renderer and intercepted HTTP, not live client TCP verification.

General effect stacks, correction masks/strength, LUTs, arbitrary temporal/spatial handles, tracking and complete professional color/audio remain open. No original runtime obligation is marked verified. No saved user project is edited/migrated and no user process is restarted.
