# Eased keyframes increment — 2026-10-17

Contract agentcut.effects.easing.v1 extends the existing v2 item_keyframes command. Outgoing interpolation accepts linear, hold, ease_in, ease_out, ease_in_out and bezier. Omission remains linear. Bezier requires numeric control1/control2 in [0,1]; controls on other modes reject. Unknown/nonfinite controls or interpolation reject atomically. Existing value/time/count/media-kind/lock limits remain unchanged.

For normalized segment time u, ease_in is u², ease_out is 1-(1-u)², and ease_in_out is 3u²-2u³. Bezier is 3(1-u)²*u*control1 + 3(1-u)*u²*control2 + u³. Segment value is first+(last-first)*curve(u). Controls are normalized **value** handles with linear time; this is not arbitrary two-dimensional time/value Bezier editing. Handles stay bounded, with no value overshoot. Endpoint clamping and hold behavior remain unchanged.

Splits and range/insert fragments restrict each cubic segment analytically, then normalize its endpoint derivatives into new bounded Bezier controls. A partial ease preset can therefore become an equivalent bezier segment after a cut. Repeated slicing preserves curve values within floating-point tolerance; no frame sampling or linear approximation is used in stored curves or rendering. Constant segments remain constant. Existing 32-point limits still apply; a fragment exceeding the cap rejects. Trim/rate/roll still retain local point times and reject stranded points unless updated in the same batch.

keyframes.mjs shares validation/evaluation, encoder expressions and slicing. operations.mjs exposes the extended schema; the inspector provides six interpolation choices and the two controls. Controls are used only when Bezier is selected. The curve plot samples each segment for display; export/preview evaluate the actual curve. Audio automation remains evaluated per decoded audio frame. No new dependency, architecture change, migration or remote service is introduced.

keyframe-tests.mjs checks exact preset quarter values, increasing/decreasing custom curves, repeated slices, split/range equivalence and invalid handles. Real FFmpeg fixtures exercise eased opacity, rotation, custom color curves and eased audio gain; the quarter-time opacity is checked against the linear alternative. Existing deterministic plan/reopen/undo tests continue to cover the shared command. Browser verification checks selecting ease_in_out and undo through the existing form, with synthetic media and intercepted HTTP plus real Store/Renderer.
